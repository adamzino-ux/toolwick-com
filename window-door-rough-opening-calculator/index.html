How to Use This Window & Door Rough Opening Calculator

Pick the Window, Exterior door or Interior door tab and enter the unit size in inches. For a window that is the outside frame size from the spec sheet. For a pre-hung door it is the slab size, such as 36 × 80. Choose your wall framing, wall height and the load above the opening, then press Calculate. You get the rough opening width and height, a header recommendation, trimmer and cripple lengths, and a cut list you can copy. The diagram updates with your numbers.

Why This Matters

A rough opening that is off by even ½″ causes real trouble. Too small, and the unit will not drop in, so you end up pulling a trimmer and re-nailing a header on the day you planned to set the window. Too large, and you burn through shims, foam and trim to hide the gap, and the unit may fall outside the manufacturer's flashing and warranty requirements.

Pre-hung doors trip up the most people. A 36″ × 80″ exterior door needs a 38″ × 82½″ opening. Framing it at 36″ × 80″, or forgetting the threshold clearance, means rework. Headers matter even more. In a bearing wall the header carries roof and floor loads around the opening, and a doubled 2×6 that is fine over a 30″ window can be badly undersized over a 5-foot slider.

Homeowners finishing a basement, remodelers swapping a window for a patio door and DIYers framing a shed all hit the same questions. How big is the opening, how deep is the header, and how long are the trimmers? This tool answers them with one consistent set of numbers.

How It's Calculated

Window: R.O. width = frame width + clearance. R.O. height = frame height + clearance. Clearance is ½″ by default (¼″ per side), or ¾″ or 1″ if you choose.
Exterior door: R.O. width = slab width + 2″. R.O. height = slab height + 2½″ + finish flooring.
Interior door: R.O. width = slab width + 2″. R.O. height = slab height + 2″ + finish flooring.

The extra width on a door covers two ¾″ jambs plus ½″ of shim room. The extra height covers the head jamb, shims and, on exterior doors, the threshold. Every rough opening is rounded up to the next 1/16″. The manufacturer's published rough opening always overrides these generic clearances.

Other dimensions. Header length = R.O. width + 3″ for each trimmer on a side, because the header sits on the trimmers between the king studs. Trimmer length = header bottom height − 1½″ bottom plate. For windows, header bottom = sill height + R.O. height. For doors it equals the R.O. height. Cripples above the header fill the space up to the underside of the double top plate: 94⅛″ for 8-ft walls, 106⅛″ for 9-ft and 118⅛″ for 10-ft.

Header sizing. This tool uses a conservative planning table, deliberately on the deeper side of typical code tables. It is not copied from IRC R602.7 and does not replace it. Headers are doubled lumber on edge with a spacer: ½″ for a 2×4 wall, 2½″ for a 2×6 wall. Anything beyond the table is flagged as engineered.

Worked Example

You are framing a 36″ × 80″ pre-hung exterior door in a 2×6 bearing wall that carries the roof plus one floor, with 8-ft walls and no finish flooring to clear.

  • R.O. width: 36″ + 2″ = 38″.
  • R.O. height: 80″ + 2½″ = 82½″.
  • Header: roof + 1 floor with a 38″ span falls in the 36–48″ band, so a doubled 2×10 is the starting point.
  • Trimmers: 38″ is over 36″, so 2 per side, 4 in total. Header length = 38″ + 6″ = 44″. With a 2×6 wall, the spacer is 2½″ thick, also 44″ long.
  • Trimmer length: 82½″ − 1½″ = 81″.
  • Cripples above: header top = 82½″ + 9¼″ = 91¾″. Underside of the top plates is 94⅛″, so the gap is 2⅜″, which gets blocking or a short cripple.

The tool shows 38″ × 82 1/2″ as the rough opening and lists the cut list above. Check it against your plans and local code before cutting.

Tips & Common Mistakes

  • Use the manufacturer's number when you have it. Window makers often specify ½″ to 1″ over frame size, and brands differ. Their rough opening beats any generic rule.
  • Measure from the subfloor. Door rough openings are measured from the subfloor, so add thick tile or hardwood to the height or the door will not swing over it.
  • Check square and level. Measure both diagonals of the opening; they should match within ⅛″. Also confirm the sill is level and the trimmers are plumb before setting the unit.
  • Do not undersize a bearing header to save lumber. If the span is past the table or you are unsure what the wall carries, get the header sized by the plans or an engineer.
  • Bedroom windows have egress rules. Minimum clear opening sizes apply, so size the window first and check egress before framing.

Frequently Asked Questions

What is a rough opening?

A rough opening is the framed hole in a wall, measured between the trimmer studs and from the subfloor or sill to the underside of the header. It is always larger than the window or door so the unit can be set plumb, shimmed and flashed.

How much bigger than the window should the rough opening be?

Typically ½″ larger than the frame in both directions, which leaves about ¼″ of shim space per side. Some manufacturers call for up to 1″, so check the installation guide and use their stated rough opening.

What is the rough opening for a 36-inch exterior door?

A 36″ × 80″ pre-hung exterior door needs a 38″ wide by 82½″ tall rough opening. That is 2″ extra in width and 2½″ extra in height for the threshold and head shims. Add finish flooring thickness if it will sit above the subfloor.

What is the rough opening for a 30-inch interior door?

A 30″ × 80″ pre-hung interior door needs a 32″ × 82″ rough opening. Interior doors use 2″ extra in both directions. Add finish flooring thickness if it will sit above the subfloor.

What size header do I need?

It depends on the span, the load above, and your local code. This tool gives a conservative starting size, such as a doubled 2×10 for a 38″ opening under roof plus one floor. Verify it against IRC R602.7 or your plans, and use an engineered header when the tool says so.

Does a 2×6 wall change the rough opening?

No. The width and height are set by the unit, not the wall. A 2×6 wall changes the header spacer, which grows from ½″ to 2½″, and the extension jambs needed on the window or door.
